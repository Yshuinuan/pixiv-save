# Pixiv 存图

一个 Tampermonkey / Violentmonkey 用户脚本：在 Pixiv 页面上一键把**当前作品的插画原图**或**小说正文**，直接保存到你预先绑定好的文件夹。

支持**多路径切换**——预先添加好几个文件夹，点一下选中，再点一下保存，不用每次重新选目录。

## 一键安装

**➡️ [点此安装 Pixiv 存图](https://raw.githubusercontent.com/Yshuinuan/pixiv-save/main/pixiv-save.user.js)**

安装前请先装好 Tampermonkey，并完成下面的[第 2 步](#2-打开允许用户脚本)——Chrome 138+ 必须手动开启该开关，否则脚本不会运行。

> 装好后脚本会通过 `@updateURL` 自动检查更新，无需手动重装。

> ⚠️ **本项目由 AI 协助开发**，作者无法保证能有效回应或修复所有问题——详见[下方说明](#关于本项目ai-协助开发)。

> 仅支持 **Chrome / Edge**。Firefox、Safari 没有 File System Access API，无法实现"直接写到你指定的文件夹"。

## 特性

- **直接写入你指定的文件夹**，不受浏览器"默认下载目录"限制，任意盘符、网络盘都行
- **多路径槽位**：`＋` 添加文件夹，点按钮选中（高亮），再点保存；选中状态会记住
- **插画**：自动识别作品页，抓取**全部页的原图**（含多图作品），保留原始 `.jpg` / `.png` 格式
- **小说**：导出 **Markdown**（带 YAML front matter）或**纯文本**，自动拆分 `[chapter:]` 章节
- **不覆盖已有文件**：同名自动加 `_2` `_3` 后缀
- **权限持久化**：目录授权存在浏览器里，重开浏览器不用重新选文件夹
- **零依赖**：单个 `.js` 文件，不加载任何外部库，不发任何第三方请求
- 失败自动重试一次、下载限速、进度实时显示

## 安装

### 1. 安装 Tampermonkey

从 Chrome 应用商店搜索「篡改猴 / Tampermonkey」并安装。（暴力猴 Violentmonkey 同样可用。）

### 2. 打开「允许用户脚本」

Chrome 138 之后，用户脚本默认被禁止执行，必须手动开启。**这一步不做的话脚本完全不会运行。**

在地址栏输入 `chrome://extensions`，找到 Tampermonkey，点 **「详细信息 / Details」**，向下滚动，打开：

```
允许用户脚本    [ 开 ]
Allow User Scripts
```

如果找不到这一项，说明你的 Chrome 早于 138 版，改用老办法：在同一页**右上角**打开 **「开发者模式 / Developer mode」**。

### 3. 安装脚本

下载 [`pixiv-save.user.js`](./pixiv-save.user.js)，把它**拖进 Tampermonkey 的管理面板**，在弹出的安装页点「安装」。

或者：Tampermonkey 面板 → 点 `+` 新建脚本 → 把文件内容全部粘贴进去 → `Ctrl+S` 保存。

### 4. 验证

打开任意 Pixiv 作品页，按 `F12` 打开控制台，应该看到：

```
[Pixiv存图] 已加载。当前页面：{type: "illust", id: "..."} | 已有路径：[]
```

页面右下角出现控制面板。

## 使用

### 添加保存路径

点面板上的 **`＋`** → 弹出系统文件夹选择窗口 → 选一个目录。

它会变成一个按钮，并自动设为当前目标。**想加几个就加几个。** 同名文件夹会自动加序号区分（`存图`、`存图 (2)`）。

### 保存

```
① 点路径按钮选中（变蓝高亮，前面出现 ✓）
② 点「存当前页」
```

面板上的「目标：」那一行会实时显示当前会存到哪里，绿色表示权限正常。

| 操作 | 效果 |
|---|---|
| 点路径按钮 | 选中为目标（高亮） |
| **点路径右侧的 `×`** | **删除这个保存路径**（只移除绑定，不删磁盘文件） |
| 双击路径按钮 | 重命名 |
| 右键路径按钮 | 菜单：重命名 / 删除 |
| `Ctrl + Shift + S` | 保存到当前选中的路径 |
| 拖动标题栏 | 移动面板位置 |
| 点 `—` | 折叠 / 展开面板 |

删除时会弹一次确认框，里面有「以后不再询问」选项。删除当前选中的路径后，会自动切换到剩下的第一个；全部删光则提示"已无保存路径"。

**选中状态会持久保存**，切换页面、重启浏览器都还在。

### 插画

打开作品页（`/artworks/<id>`），面板显示 `插画模式 · id xxxxxx`，点「存当前页」即保存全部页的原图。

### 小说

打开小说页（`/novel/show.php?id=<id>`），面板变成紫色的 `小说模式`。

在「更多设置」里选择格式：

- **`.md` Markdown**（默认）——带 YAML front matter（标题、作者、系列、标签、来源链接），章节转成 `##` 标题，封面图插入为图片链接
- **`.txt` 纯文本**——抬头信息 + 分隔线 + 正文，多章用 `【章节名】` 分隔

---

## 设置项

展开「更多设置」：

| 设置 | 默认值 | 说明 |
|---|---|---|
| 插画文件名模板 | `{id}_p{n}` | 可用 `{id}` 作品ID、`{n}` 页码（从 0 开始） |
| 小说文件名模板 | `{title}_{id}` | 可用 `{id}`、`{title}`、`{user}`、`{series}` |
| 小说保存格式 | `.md` | Markdown 或纯文本 |
| 已存在则跳过 | 开 | 同名文件直接跳过，不重复下载 |
| 插画存全部页 | 开 | 关掉则只存第 1 张 |

文件名里的非法字符（`\ / : * ? " < > |`）会自动替换成 `_`。

## 常见问题

**面板没出现，控制台也没有 `[Pixiv存图]`**

「允许用户脚本」没开。回到[第 2 步](#2-打开允许用户脚本)。

**提示"没识别到图片"**

作品被删除、受限，或 Pixiv 前端结构变了。把控制台里 `识别来源：` 那一行发出来（Issue 里贴日志即可）。

**提示"正文为空"**

小说正文拿不到，通常是这几种情况：

- **需要登录**——请确认浏览器里已登录 Pixiv
- **该章节需要单独购买**
- **R-18 作品**且账号设置里未开启显示

脚本只会读取你账号**本来就有权阅读**的内容，不会绕过任何权限。

**某些图下载失败**

Pixiv 图片服务器（`i.pximg.net`）有防盗链。脚本已通过扩展层请求自动带上正确的 `Referer`，绝大多数图片正常。少数情况下代理类扩展会干扰请求，可尝试暂时关闭。

**刷新后需要重新授权**

Chrome 有时会把目录权限降级。面板上该路径按钮会变成橙色边框，**点它一下**即可重新授权（浏览器要求授权必须发生在点击操作里）。

**Firefox 能用吗**

不能。Firefox 没有实现 File System Access API。如果你需要 Firefox 版本，只能退化成"通过浏览器下载到默认下载目录"，做不到指定任意文件夹。

## 技术说明

- **写文件**：`window.showDirectoryPicker()` 拿到目录句柄，用 `createWritable()` 直接写入。句柄可被结构化克隆，因此能存进 IndexedDB 跨会话保留。
- **取图**：必须用 `GM_xmlhttpRequest`。直接 `fetch` 原图会被 `i.pximg.net` 的 CORS 策略拦截（实测抛 `Failed to fetch`），而扩展层请求不受同源限制，并能自定义 `Referer`。
- **取小说**：请求 `/ajax/novel/{id}`，扩展层请求会自动携带你的登录 Cookie。
- **全程本地**：脚本只访问 `pixiv.net` 和 `i.pximg.net`，不向任何第三方发送数据。

## 离线自检

修改代码后可以跑自检，确认导出逻辑没坏：

```bash
node selftest-novel.js
```

它会把整个用户脚本加载进 Node 沙箱（桩掉浏览器 API），直接对内部函数做 42 项断言，覆盖章节拆分、Markdown/纯文本生成、YAML 转义、文件名模板和边界情况。

> 这个小工具抓到过三个真实 bug：一个会导致存小说时抛 `fmtDate is not defined`，一个会吃掉正文的全角空格缩进，一个会让"有缩进/无缩进"两种段落变得无法区分。
